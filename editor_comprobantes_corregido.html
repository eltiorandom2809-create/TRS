Cómo usar

1. Añade una foto. 2. Pulsa Escanear texto. 3. Edita las palabras detectadas. 4. Exporta el resultado como PNG. La fuente y el color son aproximados: el OCR detecta texto y posición, pero no puede recuperar perfectamente la tipografía original de una imagen.
